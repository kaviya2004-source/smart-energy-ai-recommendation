# Generated Outputs Index

This folder contains generated results, not source code.

| Output group | Important files |
|---|---|
| Energy EDA | `eda_daily_energy_trend.png`, `eda_monthly_energy.png`, `eda_correlation_heatmap.png` |
| Model results | `all_model_comparison.csv`, `five_model_comparison.png`, `ml_metrics.json`, `dl_metrics.json`, `hybrid_metrics.json` |
| Explainable AI | `shap_global_importance.png`, `permutation_importance.csv` |
| Forecast/recommendation | `recommendations.csv`, `future_energy_forecasts.csv` |
| Live integration | `integration/occupancy_energy_events.csv` after an image is analysed |
| Power BI | `powerbi/*.csv` |

Original and cleaned datasets are in `data/`; trained models are in `models/`; source code is in `src/` and `app/`.
