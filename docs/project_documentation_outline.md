# Major Project Documentation (70–80 pages)

1. Title page, certificate, declaration, acknowledgement, abstract (4–5 pages)
2. Introduction: problem, motivation, objectives, scope, contributions (7 pages)
3. Literature review: forecasting ML/DL, XAI, recommender systems, occupancy vision (12–14 pages)
4. Requirements and system design: use cases, architecture, data flow, hardware/software (8–10 pages)
5. Datasets and preparation: provenance, five-year filtering, dictionary, cleaning, missing values, EDA (10–12 pages)
6. Methodology: chronological split, feature engineering, 3 ML + 2 DL configurations, YOLO annotations/split, metrics (12–14 pages)
7. Results and discussion: EDA charts, all five metrics, error plots, XAI, recommendation examples, YOLO metrics (10–12 pages)
8. Deployment: Streamlit screens, Power BI dashboard design, limitations, privacy/security (5–6 pages)
9. Conclusion and future work (2–3 pages); references and appendices (code snippets, data dictionary, ethics statement).

## Journal-paper structure (8–12 pages)

Title; abstract (200–250 words); keywords; introduction; related work; materials and methods; results; discussion; conclusion; declarations; references. Never report validation accuracy as final accuracy. Include date boundaries, records/houses after cleaning, exact model parameters, test metrics, and a limitation that occupancy/YOLO data require timestamp alignment.
